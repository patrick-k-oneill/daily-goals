# The pad is the source of truth; Reminders is a mirror

The Reminders list named Today feeds suggestions onto today's Daily section (#61), and the pad stays the only record of what was written and done. A reminder reaches the goals core as plain data (`{ id, title, completed }`), so `suggestionsFor` stays pure; the device API lives in one adapter, `goals/reminders.ts`, with a no-op for the web, and loads `expo-calendar` on first use so a build without the module still starts. The list as last read is held in memory in a store of its own beside a persisted on/off switch: it is read at launch, on each return to the foreground and every minute while the app is in front (EventKit's change notice is not exposed by `expo-calendar`), and is never saved, exported in a pad file, or merged. Nothing from Reminders lands on a page by itself: a reminder is a suggestion until Add writes it as a one-off entry that records `reminderId`. A reminder with a linked entry is never offered again, finished or not, so a goal checked off on the pad does not come back the next morning because Reminders still shows it open; left unfinished, it returns as a carryover that keeps the link. The pad never writes to Reminders: completing, renaming or removing an entry leaves its reminder as it was. Reminder ids are EventKit's `calendarItemIdentifier`, local to one device, so a link that arrives by merge or pad file points at nothing on another device and is inert there. The switch is a setting of the device, off by default, and no part of the pad.

Rejected: writing unfinished reminders straight onto the page, which breaks the rule that nothing carries over without an explicit Add (#58); persisting the list, which would put a stale copy of another app's data into the pad's footprint, pad file and merge; and treating Reminders as an equal copy to reconcile, where a reminder completed or deleted elsewhere would rewrite a page. If the pad later writes back to the Today list, it does so as the owner: the entry's title and checks win, and Reminders shows what the pad says.
