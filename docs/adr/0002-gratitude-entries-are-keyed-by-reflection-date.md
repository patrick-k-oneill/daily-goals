# Gratitude entries are keyed by reflection date, not writing date

The morning journal is written about yesterday, so an entry's identity is the day it reflects on (`forDate`); when it was written is only a stamp (`writtenAt`). This is why today's page and yesterday's page host the same entry, why catching up on a missed morning edits that morning's date, and why a streak counts reflection dates. Keying by writing date was rejected because it would split one reflection across two keys whenever it is written late.
